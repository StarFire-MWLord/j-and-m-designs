# J & M Designs

Temporary holding site for **J & M Designs**, made in Wilton, CT.

The page is a white (`#FEFEFE`) field that matches the logo artwork, with the name in the mark and **Currently in development** set in black.

## Hosting

This repository is set up for [GitHub Pages](https://pages.github.com/). The live site is served from the `main` branch root (`index.html` + `logo.png`).

When the real site is ready, replace `index.html` or point the domain somewhere else and archive this repo.
